# Nexus

Nexus is a photo and video sharing social network with two independent clients.

- **Web:** React and TypeScript, deployed through GitHub Pages.
- **Android:** Native Kotlin and Jetpack Compose.
- **Backend:** Supabase authentication, database, and media storage.

Both clients share the same product experience while using platform-native interfaces.

## Features

- User accounts and profiles
- Photo and video posts
- Stories
- Likes and comments
- Following and discovery
- Saved posts
- Notifications
- Direct messages
